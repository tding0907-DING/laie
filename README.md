# 长安荔枝局｜GitHub Pages 部署项目

纯静态网页的高中历史游戏化探究活动原型。借用《长安的荔枝》的文学情境作为入口，围绕唐代荔枝产地线索、交通运输、驿传条件和贡运社会影响开展探究。

## 文件
- `index.html`：网页结构
- `style.css`：视觉样式
- `app.js`：五幕活动流程、角色、史料卡、交互和本地进度保存
- `README.md`：部署说明
- `sources.md`：史料来源、证据边界和案例转化说明

## 本地预览
解压后直接双击 `index.html`，使用现代浏览器打开即可。无需安装依赖、无需 API Key。

## GitHub Pages 部署
1. 在 GitHub 新建仓库，例如 `chang-an-lizhi-game`。
2. 将本压缩包中的五个文件放在仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/(root)`，点击保存。
6. 等待构建完成，访问 `https://你的用户名.github.io/仓库名/`。

## 功能
- 五幕流程：接旨、寻证、路线推演、议事、历史复盘
- 六种角色卡；六份史料/背景卡
- 史料展开阅读、证据收藏、产地判断
- 运输方案选择、NPC提示、观点投票
- 结案报告导出 TXT / 复制
- 浏览器 localStorage 自动保存进度
- 响应式布局，适配电脑、平板和手机

## 使用边界
- 单机静态网页。不同学生设备之间不会自动同步，不提供实时多人投票后台。
- 角色、NPC、任务期限、路线选项是教学模拟内容，不代表历史档案。
- 小说情节不能作为唐代贡运的直接史料。
- 史料卡为教学节录/整理，正式教学前请按 `sources.md` 核对权威点校本。
- 页面没有调用生成式 AI，不需要 API Key。
